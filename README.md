# Control de Gastos

Aplicación Android local para registrar gastos e ingresos, movimientos recurrentes y capturar notificaciones bancarias.

## Funciones
- Resumen mensual separado en UYU y USD.
- Alta manual de gastos e ingresos.
- Recurrentes mensuales.
- Lectura de notificaciones bancarias mediante NotificationListenerService.
- Exportación mensual a CSV.
- Datos guardados localmente en SQLite.

## APK
El workflow de GitHub Actions compila automáticamente una APK de depuración instalable como artifact `ControlGastos-APK`.
